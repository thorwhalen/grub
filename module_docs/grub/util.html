grub.util

Small shared utilities for grub: tokenizing, clamping, snippet extraction.

These are low-level helpers used across grub’s modules. They have no heavy dependencies and are safe to import anywhere.

grub.util.best_snippet(text: str, query: str, *, width: int = 240, tokenizer: ~typing.Callable[[str], ~typing.Sequence[str]] = <function simple_tokenizer>) → str[source]

Return a short excerpt of text that best matches query.

The excerpt is the single line sharing the most tokens with the query – a cheap way to show why a document matched.

>>> doc = "Intro line.\nThe quick brown fox jumps over.\nTrailing words."
>>> best_snippet(doc, "quick brown fox")
'The quick brown fox jumps over.'

With no overlap at all it falls back to the start of the text:

>>> best_snippet("alpha beta gamma", "nothing matches here", width=80)
'alpha beta gamma'
grub.util.clamp_n(n: int, size: int) → int[source]

Clamp a requested result count to [1, size].

Search backends choke when asked for more neighbours than they have documents; this keeps requests in range.

>>> clamp_n(10, 3)
3
>>> clamp_n(5, 100)
5
>>> clamp_n(0, 100)
1
