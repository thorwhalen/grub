grub.sources

Source adapters: turn anything into a searchable store.

A “store” here is just a Mapping whose values are text. Everything grub can search – a folder, a glob, a Python package, a website, a list of strings, a plain dict – is funnelled through to_store(), which detects the kind of source and returns a uniform mapping.

The single entry point is to_store(). The from_* helpers are there when you want to be explicit.

grub.sources.chunk_store(store: Mapping, *, size: int = 1500, overlap: int = 200) → dict[source]

Chunk every value of store; keys become "{key}#{n}".

>>> sorted(chunk_store({"doc": "abcdef"}, size=3, overlap=0))
['doc#0', 'doc#1']
grub.sources.chunk_text(text: str, *, size: int = 1500, overlap: int = 200) → list[str][source]

Split text into overlapping character windows.

Long documents search better in pieces: a hit then points at a passage instead of a whole file.

>>> chunk_text("abcdefghij", size=4, overlap=1)
['abcd', 'defg', 'ghij', 'j']
>>> chunk_text("short", size=100)
['short']
grub.sources.from_dir(directory: PathLike | str, *, recursive: bool = True, extensions: Iterable[str] | None = None, encoding: str = 'utf-8', max_bytes: int = 1000000, skip_dirs: Iterable[str] = frozenset({'.eggs', '.git', '.hg', '.idea', '.mypy_cache', '.pytest_cache', '.ruff_cache', '.svn', '.venv', '.vscode', '__pycache__', 'build', 'dist', 'node_modules', 'venv'})) → dict[source]

Every decodable text file under directory, keyed by relative path.

Binary files, oversized files, and noise directories (.git, __pycache__, node_modules, …) are skipped automatically.

Read the given files into a {name: content} dict.

Keys are file names; if names collide the relative path is used.

grub.sources.from_urls(urls: Iterable[str], *, encoding: str = 'utf-8', timeout: float = 30.0) → dict[source]

Fetch URLs and return {url: text} with HTML stripped to text.

Uses only the standard library. Unreachable URLs are skipped.

grub.sources.html_to_text(html: str) → str[source]

Strip HTML tags, returning visible text only.

>>> html_to_text("<h1>Title</h1><p>Hello <b>world</b></p>")
'Title Hello world'
>>> html_to_text("<style>.x{}</style><p>visible</p>")
'visible'
grub.sources.to_store(source, *, recursive: bool = True, extensions: Iterable[str] | None = None, chunk: int | tuple[int, int] | None = None, encoding: str = 'utf-8', max_bytes: int = 1000000) → Mapping[source]

Coerce source into a Mapping[str, str] ready to be searched.

source may be:

  • a Mapping – used as-is

  • a folder path – every (decodable) text file under it

  • a glob pattern – every matching file

  • a "path/{}.ext" format – a lazy py2store text store

  • a Python module/package – its .py source files

  • a URL (or list of URLs) – fetched and stripped to text

  • a list of strings – enumerated into {"0": ..., "1": ...}

  • an iterable of (key, value) pairs – turned into a dict

>>> store = to_store({"a": "first doc", "b": "second doc"})
>>> dict(store)
{'a': 'first doc', 'b': 'second doc'}
>>> sorted(to_store(["red", "green", "blue"]))
['0', '1', '2']
Parameters:

  • recursive – walk sub-directories (folder sources only).

  • extensions – keep only files with these extensions, e.g. [".py"].

  • chunk – split values into overlapping windows – an int size or a (size, overlap) pair. Handy for long documents.

  • encoding – text encoding for files.

  • max_bytes – skip files larger than this (folder/glob sources).
