grub.searcher

The Searcher – grub’s unified, modern search object.

A Searcher wraps three things behind one friendly interface:

  • a store (any source, via grub.sources.to_store()),

  • a backend (TF-IDF, semantic, or hybrid, via grub.backends),

  • results enriched with scores and snippets (grub.results).

You rarely build one by hand – grub.grub() is the front door – but the class is here when you want full control, persistence, or to plug in your own backend.

class grub.searcher.Searcher(source, *, method: str = 'tfidf', n_results: int = 10, tokenizer=<function camelcase_and_underscore_tokenizer>, embed=None, model: str = 'all-MiniLM-L6-v2', alpha: float = 0.5, chunk=None, snippets: bool = True, backend: Backend | None = None, **source_kwargs)[source]

Index any source and search it.

>>> docs = {
...     'python': 'Python is a popular high level programming language.',
...     'guitar': 'A guitar is a musical instrument with six strings.',
...     'coffee': 'Coffee is a hot drink brewed from roasted beans.',
... }
>>> searcher = Searcher(docs)
>>> searcher
<Searcher: tfidf index over 3 documents>
>>> results = searcher('a musical instrument')
>>> results.keys[0]
'guitar'
>>> searcher('hot drink brewed from beans').keys[0]
'coffee'

Each result carries a score and a snippet explaining the match:

>>> hit = results[0]
>>> hit.key
'guitar'
>>> hit.score > 0
True
>>> 'musical instrument' in hit.snippet
True
