grub¶

grub – a ridiculously simple search engine factory.

Point grub at anything – a folder, a Python package, a website, a dict, a list of strings – and get back a search engine in one line:

from grub import grub

search = grub('./my_docs')              # build a searcher
results = search('how do I configure logging')

for hit in results:
    print(hit.score, hit.key, hit.snippet)

Or search in a single call:

grub('./my_docs', 'how do I configure logging')

Three search methods are available: 'tfidf' (lexical, the default), 'semantic' (embeddings – pip install grub[semantic]), and 'hybrid' (a blend of both).

class grub.SearchStore(store, n_neighbors=10, tokenizer=<function camelcase_and_underscore_tokenizer>)[source]¶

Bases: StoreMixin

Build a search index for anything (that is given a mapping interface with string values).

A store is anything with a collections.Mapping interface. Typically, a store’s backend comes from local files or data-base wrapped into a mapping (see py2store for tools to do that!). For testing purposes though, we’ll use a dict here:

>>> store = {
... "Nelson Mandela": "The greatest glory in living lies not in never falling, but in rising every time we fall.",
... "Walt Disney": "The way to get started is to quit talking and begin doing.",
... "Steve Jobs": "Your time is limited, so don't waste it living someone else's life."
... }
>>> search = SearchStore(store, n_neighbors=2)  # our store is small, so need to restrict our result size to less
>>> list(search('living'))
['Steve Jobs', 'Nelson Mandela']

A SearchStore instance is picklable.

>>> import pickle
>>> unserialized_search = pickle.loads(pickle.dumps(search))
>>> list(unserialized_search('living'))
['Steve Jobs', 'Nelson Mandela']

grub.grub(source, query=None, *, method='tfidf', n=10, **kwargs)[source]¶

Search anything, in one line.

Point grub at a source – a folder, a glob, a Python module, a URL, a dict, or a list of strings – and it builds a search engine.

Called with just a source it returns a reusable Searcher:

>>> docs = {
...     'python': 'Python is a popular programming language.',
...     'guitar': 'A guitar is a musical instrument with strings.',
...     'coffee': 'Coffee is a hot drink brewed from beans.',
... }
>>> searcher = grub(docs)
>>> searcher('a musical instrument').keys[0]
'guitar'

Called with a query too, it searches immediately and returns the SearchResults:

>>> grub(docs, 'hot drink brewed from beans').keys[0]
'coffee'
Parameters:

  • source – anything grub.sources.to_store() understands. An existing Searcher is reused as-is.

  • query (str | None) – if given, search for it and return results; otherwise return the searcher.

  • method (str) – 'tfidf', 'semantic', or 'hybrid'.

  • n (int) – number of results.

  • kwargs – forwarded to Searcher (e.g. chunk=1500, extensions=['.py'], embed=...).

grub.to_store(source, *, recursive=True, extensions=None, chunk=None, encoding='utf-8', max_bytes=1000000)[source]¶

Coerce source into a Mapping[str, str] ready to be searched.

source may be:

  • a Mapping – used as-is

  • a folder path – every (decodable) text file under it

  • a glob pattern – every matching file

  • a "path/{}.ext" format – a lazy py2store text store

  • a Python module/package – its .py source files

  • a URL (or list of URLs) – fetched and stripped to text

  • a list of strings – enumerated into {"0": ..., "1": ...}

  • an iterable of (key, value) pairs – turned into a dict

>>> store = to_store({"a": "first doc", "b": "second doc"})
>>> dict(store)
{'a': 'first doc', 'b': 'second doc'}
>>> sorted(to_store(["red", "green", "blue"]))
['0', '1', '2']
Parameters:

  • recursive (bool) – walk sub-directories (folder sources only).

  • extensions (Optional[Iterable[str]]) – keep only files with these extensions, e.g. [".py"].

  • chunk (int | tuple[int, int] | None) – split values into overlapping windows – an int size or a (size, overlap) pair. Handy for long documents.

  • encoding (str) – text encoding for files.

  • max_bytes (int) – skip files larger than this (folder/glob sources).

Return type:

Mapping
