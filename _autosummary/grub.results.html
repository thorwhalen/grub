grub.results¶

Rich search results: keys, scores, and snippets that explain a match.

Where the legacy grub.SearchStore returns a bare array of keys, the modern grub.Searcher returns a SearchResults – a list of SearchResult records that also know their score and a snippet showing why the document matched.

Parameters:

  • key (str) – the document’s key in the store.

  • score (float) – relevance in [0, 1] (higher is better).

  • snippet (str) – a short excerpt showing why the document matched.

class grub.results.SearchResults(results=(), *, query=None)[source]¶

Bases: list

An ordered list of SearchResult, best match first.

It is a list, so it indexes, slices, and iterates as you’d expect:

>>> results = SearchResults(
...     [SearchResult("guitar", 0.9, "a string instrument"),
...      SearchResult("piano", 0.4, "a keyboard instrument")],
...     query="instrument",
... )
>>> len(results)
2
>>> results[0].key
'guitar'
>>> results.keys
['guitar', 'piano']
>>> [round(s, 1) for s in results.scores]
[0.9, 0.4]
>>> results.as_dict()['guitar']
0.9
